📊 TrainTraq Overdue Reminders

Upload your Excel file to separate records into Followups and Removals based on work period validity

📝 What this tool does:

  1. Reads your Excel file with "OverdueCourses" and "EmployeeAWPs" tabs
  2. Note* get the EmployeeAWPs file from the Employee Details report in Tableau: Employee Detail
  3. Cross-references UINs from column A in both tabs
  4. Checks if today's date (the date you run the report) falls within work period dates
  5. Creates "Followups" tab: UINs WITHIN their current work period (keep these)
  6. Creates "Removals" tab: UINs OUTSIDE their current work period (consider removing)
  7. Adds date range columns to both new tabs for easy reference
  8. NEW: Creates "Addendum A" document from Removals tab for official documentation

Result: Clean separation of records based on work period validity, plus professional addendum document for removal justification.

  • EmployeeAWPs - Download Tableau Employee Details Report
